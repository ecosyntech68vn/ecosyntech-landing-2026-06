  • ✓ Triple-source weather failover (Open-Meteo + GAS + cảm biến)
  • ✓ Audit blockchain cho EUDR/CBAM
  • ✓ Multi-tenant pilot Q4 2026

Express + SQLite + MQTT aedes nhúng. Boot ≤ 20 giây trên Raspberry Pi 4. Dashboard tiếng Việt. Mất Internet 24h vẫn tưới đúng, không mất dữ liệu.

  • ✓ 250+ module phần mềm đã kiểm thử
  • ✓ JWT auth + per-device HMAC
  • ✓ Auto-retention dữ liệu cũ (90 ngày default)
L2 — Thiết bị thông minh

Firmware V9.4.1 — Chip IoT công nghiệp

ESP32 base. Khóa bảo mật DEVICE_SECRET riêng từng máy. OTA tự cập nhật + tự khôi phục nếu boot fail. SHA-256 verify trước khi flash.

  • ✓ MQTT publish 5s/lần, dedup nhúng
  • ✓ Boot health check + rollback timeout
  • ✓ Canonical JSON v2 byte-perfect

Tin cậy

Nguồn dữ liệu duy nhất

Thiết bị là nguồn duy nhất ghi nhận dữ liệu lên blockchain. Đối thủ copy giao diện rất nhanh — copy lớp tin cậy này phải xây lại từ phần cứng.

Bảo mật

Chữ ký số đầu cuối

Mỗi gói dữ liệu được ký bằng khóa riêng từng thiết bị. Định dạng đồng nhất tuyệt đối giữa thiết bị · phần mềm trang trại · đám mây. Không thể giả mạo.

Dữ liệu

Bánh đà dữ liệu thực địa

Sương muối Mộc Châu, mưa phùn ĐBSH, gió Lào, ẩm cao Hà Giang. AI tại biên học từ dữ liệu thật — càng dùng càng chính xác. Đối thủ phải mất 3 năm khảo sát mới đuổi kịp.
